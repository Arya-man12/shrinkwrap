Shrinkwrap

Convert and compress images, PDFs and data files in your browser. Nothing is uploaded.

Output format
Quality
80%

Lower quality gives smaller files. 70 to 85 is usually hard to tell apart.

Images smaller than this are never enlarged.

Drop images here, or tap to choose PNG, JPG, WebP, GIF, BMP or SVG. You can also paste from the clipboard.

    Action

    Every page of every PDF in the list, on one board. Drag pages to reorder them, or use the buttons under each page. Everything saves as one PDF; tick pages to save just those.

    Gaps and blank pages

      Page numbers

      The first numbered page gets the start number. Numbers follow the board order and stay upright on rotated pages.

      Joins every PDF in the list into one file, top to bottom. Use the arrows on each file to change the order.

      Split into

      Each comma makes a new file. 1-3, 4, 8- gives three files; 8- runs to the last page.

      Image quality
      70%

      Shrinks the photos and scans inside a PDF. Text and drawings stay sharp and selectable, so PDFs that are mostly text get only a little smaller.

      Drop PDFs here, or tap to choose Any number of PDF files. Password-protected PDFs need unlocking first.

          Tap a page to select it. On a phone, press and hold a page, then drag it.

          Action

          Takes a list of records. A file shaped like {"items": [...]} uses that inner list.

          Checks each file is valid JSON and points to the line of the first mistake.

          Change this only if accented letters come out garbled. Output is always UTF-8.

          Drop text files here, or tap to choose CSV, TSV, JSON, TXT and other plain text. You can also paste text.

            Conversion uses your browser's own image encoder, so metadata such as camera data and location is removed from the output. Transparent areas become white when you convert to JPG.

            PDFs are read and rebuilt in this page with pdf-lib, and page previews are drawn here with pdf.js. Compressing re-encodes photos inside the PDF as JPEG and never makes a file bigger: if nothing shrinks, the original is kept. Form fields, links and bookmarks may not survive a merge or split.

            Files are read and rewritten in this page; nothing leaves your device. Everything is saved as UTF-8. Whole numbers longer than 15 digits, such as some IDs, can lose precision when converted to JSON values, so they are kept as text.
